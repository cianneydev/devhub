# 📊 Projets

Les projets vous permettent d'organiser votre travail au quotidien.

## 📋 Commandes disponibles

| Commande | Description |
|---|---|
| `devhub project add <nom> [description]` | Ajouter un projet |
| `devhub project list` | Lister tous les projets |
| `devhub project show <nom>` | Afficher un projet |
| `devhub project remove <nom>` | Supprimer un projet |

## ➕ Ajouter un projet

```bash
devhub project add "Mon site" "Un portfolio en Next.js"
