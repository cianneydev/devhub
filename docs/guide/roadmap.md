# 🗺️ Vision & Roadmap

DevHub n'est pas seulement un CLI. C'est le début d'un écosystème pour développeurs, porté par **CIANNEY LABS**.

## 🎯 Notre vision

> **Devenir le hub central du développeur, du terminal au cloud.**

Nous croyons qu'un développeur ne devrait pas avoir à jongler entre 10 outils pour gérer ses snippets, ses notes, ses projets et son code. DevHub centralise tout, en commençant par le terminal (100% local), puis en s'étendant vers le cloud.

## 🚀 Les 3 piliers de DevHub

### 1. DevHub CLI (disponible)
- ✅ 8 commandes (snippets, notes, recherche, copie, statistiques, export/import, TUI)
- ✅ 100% local, ultra rapide
- ✅ Open source (MIT)

### 2. DevHub Web (en développement)
- 🔄 Synchronisation cloud (optionnelle)
- 🖥️ Éditeur de code en ligne
- 🤖 Assistant IA pour générer, expliquer et corriger du code
- 👥 Collaboration et partage

### 3. DevHub Ecosystem (à venir)
- 🧩 Extensions pour VSCode, Neovim, JetBrains
- 📦 Marketplace de snippets communautaires
- 🔌 API publique
